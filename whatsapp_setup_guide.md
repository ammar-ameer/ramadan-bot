# WhatsApp Cloud API Setup Guide

This guide will help you set up a Meta Developer account and get the necessary credentials for your Ramadan Bot.

## 1. Create a Meta Developer Account
1.  Go to [developers.facebook.com](https://developers.facebook.com/).
2.  Log in with your Facebook account.
3.  Click **My Apps** -> **Create App**.
4.  Select **Other** (or "Business") as the app type.
5.  Select **Business** as the app type if prompted again.
6.  Enter an App Name (e.g., "Ramadan Bot") and contact email.
7.  Click **Create App**.

## 2. Add WhatsApp Product
1.  On the App Dashboard, scroll down to find **WhatsApp**.
2.  Click **Set up**.
3.  Select a Meta Business Account (or create a new one if needed).
4.  Click **Continue**.

## 3. Get Temporary Credentials
You will be redirected to the **WhatsApp > API Setup** panel. Here you will find:
-   **Temporary Access Token**: Expires in 24 hours. Good for testing.
-   **Phone Number ID**: The ID of the test phone number provided by Meta.
-   **WhatsApp Business Account ID**: (Not strictly needed for the bot, but good to keep).

**Action:** Copy the `Temporary Access Token` and `Phone Number ID` into your `.env` file.

## 4. Add Recipient Phone Numbers
> **IMPORTANT**: While in "Development" mode (using the Test Number), you **MUST** verify every single phone number you want to message.

1.  In the **API Setup** panel, scroll to "Step 2: Send and receive messages".
2.  Click the **Manage phone number list** dropdown or link.
3.  You can add up to **5 phone numbers** for free testing.
4.  Enter each number and verify it with the OTP code sent to that phone.
5.  **Only verified numbers will receive messages.**

**Action:**
1.  Verify all the numbers you want to message in the Dashboard.
2.  Add them to your `.env` file as a comma-separated list:
    ```properties
    RECIPIENT_PHONE_NUMBERS=919876543210,919876543211
    ```

## 5. (Optional but Recommended) Permanent Token
The temporary token expires in 24 hours. For a bot running all month, you need a **System User Token**.
1.  Go to [business.facebook.com/settings](https://business.facebook.com/settings).
2.  Navigate to **Users > System Users**.
3.  Add a new System User (Role: Admin).
4.  Click **Generate New Token**.
5.  Select your App ("Ramadan Bot").
6.  Select Permissions: `whatsapp_business_messaging` and `whatsapp_business_management`.
7.  Click **Generate Token**.
8.  Copy this token to your `.env` as `WHATSAPP_ACCESS_TOKEN`.

## 6. Configure Webhook (For hosting)
> **Note:** You can SKIP this step if you only want to *send* messages. You only need this if you want to *receive* messages or status updates.

### Option A: Local Testing (Recommended before deployment)
If you want to test the webhook locally without deploying:
1.  Install **ngrok**: `npm install -g ngrok` (or download from ngrok.com).
2.  Start your bot: `npm run dev`.
3.  In a new terminal, run: `ngrok http 3000`.
4.  Copy the HTTPS URL generated by ngrok (e.g., `https://random-id.ngrok-free.app`).
5.  Use this URL + `/webhook` in the Meta Dashboard (e.g., `https://random-id.ngrok-free.app/webhook`).
6.  Verify Token: `ramadan_bot_token`.

### Option B: Wait for Deployment
If you prefer, you can wait until you deploy to Railway/Render to get a public URL.

## 7. Push Code to GitHub & Deploy
To deploy, you first need to push your code to GitHub.

1.  **Create a Repository on GitHub**:
    -   Go to GitHub.com and create a new repository (e.g., `ramadan-bot`).
    -   Do *not* initialize with README/gitignore (we already have them).

2.  **Push Local Code**:
    Run these commands in your VS Code terminal:
    ```bash
    git remote add origin https://github.com/YOUR_USERNAME/ramadan-bot.git
    git branch -M main
    git push -u origin main
    ```

3.  **Deploy**:
    -   Go to Railway/Render.
    -   Connect your GitHub account.
    -   Select the `ramadan-bot` repo.
    -   Add your Environment Variables.
    -   Deploy!

🎉 **You are now ready to send messages!**
